## 📂 Projects

### 1. Grocery Store Manager 🛒

A simple console-based grocery store management program.

**Features:**

* Add items
* Remove items
* Search items
* Show all items
* Update item information
* Exit the program

**Item information includes:**

* Item name
* Item price
* Manufacturer date
* Expiry date

**Concepts practiced:**

* Lists
* Nested lists
* `if/elif/else`
* `for` loops
* `while` loops
* `input()`
* `append()`
* `pop()`
* List indexing
* Updating list elements

More projects will be added as I continue learning Python.
